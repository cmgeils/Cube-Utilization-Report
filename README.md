# Cube Utilization Report

## Project Overview

This project was developed in Microsoft Excel to automate the analysis of trailer cube utilization and outbound line performance. The report transforms raw operational data into an interactive dashboard that evaluates utilization, ranks outbound areas, and identifies destinations performing above or below target.

The report is designed so that users can refresh the workbook with new data rather than rebuilding reports manually.

---

## Business Objective

The goal of this project is to provide operations management with a dashboard that:

- Measures trailer cube utilization against a utilization goal.
- Identifies outbound areas requiring operational attention.
- Highlights the highest and lowest performing destinations.
- Tracks transportation costs associated with trailer movement.
- Reduces manual reporting by using PivotTables, Power Query, and dynamic Excel formulas.

## Data Preparation

The report imports raw trailer utilization data and performs the following steps:

- Cleans and organizes source data.
- Merges lookup tables using Power Query.
- Creates calculated utilization metrics.
- Builds PivotTables for summarized reporting.
- Uses dynamic formulas to populate the dashboard automatically.

---

## Dashboard Features

### Weekly Report
- Overall cube utilization
- Goal vs. actual utilization
- Total trailer loads
- Transportation costs
- Outbound area rankings
- Top-performing destinations
- Destinations requiring additional improvement

### Daily Report
Provides the same operational metrics for an individual reporting day to support daily decision making.
